# Arena frame: KetoKasse landing design

## Artifact

Each candidate produces a design package under its directory:
- `design.md` (usage, types, module map, signatures, rationale)
- `copy-no.md` (Norwegian UI strings)

## Rubric

1. Day exclusivity is encoded in a structure (not free-form booleans).
2. Next delivery date is derived, not stored as editable truth.
3. Page keeps the prescribed vertical stack with no overlapping elements.
4. Public surface for signup is small; payment stays at a boundary.
5. Norwegian copy covers every user-visible string in the stack.
6. Homestead / keto farmer direction is named in concrete tokens (not purple / cream-terracotta cliché).

- A: progressive reveal state machine
- B: single-scroll draft + pure derivation
